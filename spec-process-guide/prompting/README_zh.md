## 关键原则

规范开发中的有效提示遵循以下原则：

1. **保持具体** - 提供清晰的上下文和具体示例
2. **结构化请求** - 将复杂要求分解为可管理的部分
3. **深思熟虑地迭代** - 在前一响应基础上构建而不是重新开始
4. **验证理解** - 在进入下一阶段前确认一致性

## 常见模式

- **上下文设置** - 建立项目背景和约束条件
- **阶段转换** - 在需求、设计和任务之间平稳过渡
- **反馈集成** - 有效融入变更和改进
- **质量验证** - 确保输出满足您的标准
